# Bundled interface font

LXGW WenKai Regular 1.522 is reused unchanged from the official
`lxgw/LxgwWenKai` release: https://github.com/lxgw/LxgwWenKai/releases/tag/v1.522

SHA256: `39ad71264b588165b469e35e6afb162a378dacd1f95348160240ba9038ac3009`

The complete SIL Open Font License is in `LXGWWenKai-OFL.txt` beside the font.
This is an optional built-in choice. The original interface font remains the
default. Imported fonts stay in the desktop application's user-data directory,
are loaded only by the app and are never installed into the operating system.

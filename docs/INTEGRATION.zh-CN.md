# Dashboard 配套开发

Dashboard 是 desktop 的固定子模块，不拥有独立的 Windows 安装／更新通道。文档以产品 1.14.2-may.26 为基线。

## 环境和命令

核对父仓库 gitlink、当前子模块提交、锁文件、协议生成物和 desktop 桥接。固定 pnpm 11.19.0，Node 按父仓库要求。生成依赖也有子模块／固定输入，不要以浮动上游文件替换。

从已准备好的子模块根目录可按需执行：

```bash
pnpm install --frozen-lockfile
pnpm lint
pnpm lint:css
pnpm test
pnpm build
```

`generate` 和 `generate:dev` 有代码／协议输入要求，后者依赖脚本中写定的同级核心路径，不能在任意目录照抄。优先使用 desktop 的顶层准备和构建流程。独立 Vite 只提供页面开发服务，不代表 IPC、认证或代理已经运行。

## 界面与后端合同

概览、组、连接和日志使用后端状态。故障切换卡片按实际检测组纵向展示，不把正在编辑的组当作唯一监测组；编辑器保留每组顺序和上次查看选择。启动恢复前不能从空状态推断需要重载。

隐藏页面可以暂停可重放展示，但必要连接历史与未保存草稿必须保留。语言只维护简中和英文；原生菜单与字体由平台决定。改 UI 需要类型、组件及相关 desktop Electron 验证；纯文档不需要启动代理或重装应用。

## 提交与配套

子模块是独立 Git 仓库。源码功能更新在子仓库验证并提交后，父仓库再显式选择新 gitlink；不能只提交父仓库指针而遗漏来源。纯文档更新不要求重建二进制或静默调整已固定来源。

所有公开示例脱敏。应用日志、订阅、节点凭据和用户数据库不进入测试夹具或截图。最终产品功能、平台和故障处理见[desktop 文档](https://github.com/mxh110708/may-route-desktop/blob/custom-main/docs/README.md)。
